# Cinema API

Серверна частина сервісу кінотеатру на NestJS. Дані зберігаються в масивах усередині сервісів і зникають після перезапуску процесу. База даних не підключається.

## Встановлення залежностей

```bash
npm install
```

## Запуск у режимі розробки

```bash
npm run start:dev
```

Застосунок слухає порт з `PORT` (за замовчуванням `3000`). Документація Swagger доступна на [http://localhost:3000/docs](http://localhost:3000/docs).

Послідовні HTTP-запити для перевірки маршрутів лежать у `requests.http`.

## Приклад файлу `.env`

Скопіюйте змінні в файл `.env` у корені проєкту:

```env
PORT=3000
```

| Змінна | Приклад | Опис |
| --- | --- | --- |
| `PORT` | `3000` | Порт HTTP-сервера |
